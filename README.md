# Pokemon vs Pokemon - Tower Defense Game

A fun web-based tower defense game inspired by Plants vs Zombies, but featuring Pokemon characters! Defend your base against waves of attacking Pokemon using your strategic placement of defending Pokemon.

## How to Play

1. **Select Pokemon**: Click on a Pokemon card from the left panel to select it
2. **Place Pokemon**: Click on any grid square to place your selected Pokemon
3. **Start Waves**: Click "Start Wave" to begin the attack
4. **Collect Sun**: Sun drops (☀️) fall from the sky - collect them for more resources
5. **Defend**: Don't let attacking Pokemon reach your base!

## Pokemon Types

### Defending Pokemon
- **🌱 Bulbasaur** (25☀️) - Basic grass type with moderate damage
- **🔥 Charmander** (50☀️) - Fire type with high damage and fast attack speed
- **💧 Squirtle** (75☀️) - Water type with high health and long range
- **⚡ Pikachu** (100☀️) - Electric type with highest damage and fastest attack speed

### Attacking Pokemon
- **🐀 Rattata** - Basic attacker with moderate health
- **🦇 Zubat** - Fast flying attacker
- **🐍 Ekans** - Slow but tough snake
- **🐱 Meowth** - Balanced attacker

## Game Controls

- **Start Wave**: Begin the next wave of attackers
- **Pause/Resume**: Pause or resume the game
- **Restart**: Start a new game

## Features

- Grid-based placement system
- Multiple Pokemon types with different abilities
- Wave-based progression with increasing difficulty
- Sun collection system for resources
- Health bars for all Pokemon
- Projectile-based combat system
- Responsive design for different screen sizes

## How to Run

Simply open `index.html` in any modern web browser. No additional setup required!

## Game Mechanics

- Each Pokemon has unique stats: health, damage, range, and attack speed
- Sun drops appear every 5 seconds and can be collected for 25☀️
- Defeating attacking Pokemon rewards 10☀️
- Waves get progressively harder with more attackers
- You lose a life when an attacker reaches your base
- Game ends when you lose all 3 lives

Enjoy defending your Pokemon base! 🎮
